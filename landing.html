Comenzar

3 pasos para activar tu ecosistema.

Instala el plugin en Claude Code y convierte tu terminal en el consultor técnico más riguroso de Sofka.

Paso 01
Clonar el repositorio
Clona el repo en tu directorio de plugins de Claude Code.
git clone https://github.com/javiermontano-sofka/sofka-discovery-framework.git
~/skills/plugins/sofka-discovery-framework
Paso 02
Configurar CLAUDE.md
Copia el CLAUDE.md del repo a tu configuración global para activar el enrutamiento de comandos /sdf:.
# Lee el CLAUDE.md del repo
# para instrucciones completas
Paso 03
Ejecutar tu primer discovery
Usa el comando express para validar la instalación con un Go/No-Go rápido.
/sdf:run-express
