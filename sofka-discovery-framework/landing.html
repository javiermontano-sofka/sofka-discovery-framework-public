01

Qué es el Discovery Framework

Un framework de discovery técnico empresarial orquestado por agentes de IA dentro de Claude Code. 48 skills especializados trabajan en equipo para producir entregables de calidad consultoría en formato markdown-first, con diagramas Mermaid, variantes ejecutiva/técnica, y quality gates automáticos.

🔍

Discovery Completo

Del stakeholder mapping al handover operacional en un pipeline orquestado de 7 fases + 3 gates.

🤖

Dream Team IA

8 agentes especializados que debaten, validan y producen artefactos como un equipo real de consultoría.

📄

Markdown-First

Output en markdown-excellence con tablas semáforo, Mermaid, TL;DR, footnotes y evidence tags.

🔒

Quality Gates

3 gates automáticos que validan coherencia, completitud y calidad antes de avanzar de fase.

Dream Team de Agentes

8 agentes especializados que funcionan como un equipo real de consultoría. Cada uno aporta una perspectiva única y valida el trabajo de los demás.

Orchestrator

Orquestador imparcial. Secuencia fases, enforce gates, gestiona contratos de datos. No analiza — solo coordina.

Architecture

Diseño de sistemas, evaluación de patrones, quality attributes y trade-offs de arquitectura. Fases 1–4.

Domain Analyst

SME por industria: contexto regulatorio, benchmarks competitivos, validación de negocio. Activa lens según sector.

Engineering

Perspectiva de implementación real. Code-level analysis, infraestructura, DevOps. Detecta planes que no sobreviven la realidad.

Delivery

Delivery Manager

Timelines, scope, riesgos, stakeholder comms, presupuesto. Mantiene el pipeline en tiempo y forma.

Quality

Valida cada entregable contra criterios de aceptación. Coherencia cross-phase. Nada pasa un gate sin su review.

Data

Data Strategist

Arquitectura de datos, gobernanza, migración, calidad, analytics pipelines. Datos como ciudadano de primera clase.

Change

Change Catalyst

Readiness organizacional, adopción, training, gestión de resistencia. El lado humano de la transformación.

05

Orquestación Claude Code

Claude Code actúa como runtime: el usuario invoca un comando, el conductor orquesta, los skills ejecutan, los agentes validan y el output se entrega en el formato elegido.

Invocación del Usuario

El usuario ejecuta /sofka-discovery-framework:discovery y proporciona los inputs iniciales: repo URL, industria, stakeholders.

Conductor Activa el Pipeline

El discovery-conductor declara el comité de expertos, construye el discovery plan, valida inputs mínimos y presenta el plan al usuario.

Sub-Agentes por Fase

Claude Code spawns agentes especializados para cada fase. Cada agente activa los skills relevantes, produce artefactos y pasa contratos de datos a la siguiente fase.

Quality Gate Validation

El quality-guardian valida cada entregable contra criterios de aceptación. Verifica coherencia cross-phase. Si no pasa, se itera.

Output Delivery

Entregables en el formato solicitado (markdown/html/docx/dual) con la variante elegida (ejecutiva ~40% o técnica completa).

Sub-Agent Dynamic: El conductor no ejecuta análisis. Cada fase es delegada a un sub-agente fork que tiene acceso a los skills de esa fase, los datos de fases previas, y las instrucciones del conductor. El resultado vuelve al conductor para validación y routing.

08

Modos de Ejecución

Cuatro modos de interacción human-in-the-loop (HITL) que se adaptan al nivel de supervisión deseado.

Modo Comportamiento HITL Uso ideal
piloto-auto default Autónomo en trabajo rutinario, pausa en gates y ambigüedades En gates + ambigüedades Discoveries estándar
desatendido Cero interrupciones, todo auto-resuelto Ninguno Batches, re-ejecuciones
supervisado Autónomo con reportes en milestones Reportes periódicos Leads que quieren visibilidad
paso-a-paso Confirma antes de cada sección/fase Cada sección Training, onboarding, debugging
Tip: Usa MODO=paso-a-paso para tu primer discovery. Una vez familiarizado, cambia a piloto-auto para máxima productividad.
09

Excellence Loop

Cada skill se refina mediante un ciclo de excelencia de 10 criterios. El objetivo: que cada skill alcance nivel moat — ventaja competitiva sostenible.

1. Clarity Instrucciones inequívocas, sin ambigüedad
2. Completeness Todos los casos cubiertos, edge cases documentados
3. Consistency Terminología y formato uniformes
4. Actionability Output directamente usable, no genérico
5. Evidence Cada afirmación trazable a evidencia
6. Trade-offs Pros/cons explícitos, nunca one-sided
7. Modularity Self-contained, sin dependencias cruzadas
8. Validation Gate Criterios de aceptación verificables
9. Progressive Disclosure Resumen primero, detalle bajo demanda
10. Cross-Reference Links a skills relacionados para contexto expandido

Quick Start

Tres comandos para empezar. Instala el plugin, elige tu modo y lanza tu primer discovery.

1. Instalación

# Registra el plugin en Claude Code
$ claude --plugin-dir ./sofka-discovery-framework

2. Discovery Guiado

# Pipeline guiado con confirmaciones en gates
> /sofka-discovery-framework:discovery

3. Discovery Autónomo

# Pipeline autónomo end-to-end
> /sofka-discovery-framework:discovery-auto

4. Parámetros Opcionales

# Ejemplos de parámetros
> /sofka-discovery-framework:discovery \
    INDUSTRIA=banking \
    MODO=paso-a-paso \
    FORMATO=dual \
    VARIANTE=ejecutiva
Filosofía de costos: El framework produce drivers de costo, inductores de esfuerzo y magnitudes indicativas — nunca precios finales. Costear ≠ Cobrar. Las magnitudes incluyen un 5% de margen de innovación para excelencia operacional.
