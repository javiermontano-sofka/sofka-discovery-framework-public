Data Mesh Readiness Assessment

3.5/5
Domain Ownership
7 dominios claros. Equipos por dominio. Pero datos analiticos centralizados en DW.
2.0/5
Data as a Product
No existe concepto de data product. Sin SLAs, sin quality metrics, sin ownership por dataset.
2.5/5
Self-Serve Platform
Snowflake + dbt + Airflow existen. Pero todo pasa por equipo central. Queue: 3 semanas.
3.0/5
Federated Governance
Alation parcial (60%). Politicas PII definidas. Pero enforcement manual, no automatizado.
Veredicto: GO condicional La organizacion tiene prerequisitos organizacionales (dominios claros, equipos, liderazgo). Los gaps criticos son Data as a Product (concepto nuevo) y Self-Serve Platform (requiere inversion). Recomendacion: piloto en 2 dominios antes de adopcion full.

S5

Federated Governance Model

7 Politicas Globales

  1. Naming: {domain}.{entity}.{qualifier} — enforced in CI/CD
  2. Schema: backward-compatible evolution — Schema Registry validation
  3. PII: classified and encrypted — auto-detection + Snowflake masking
  4. Quality: accuracy >95%, completeness >95% — Great Expectations in CI/CD
  5. Documentation: data dictionary + SLA + owner — template validation
  6. Retention: min 90 days, max per classification — lifecycle policies
  7. Access: role-based, request + approval — Alation + Snowflake RBAC

Each domain implements these globally-defined policies locally. The platform team provides tooling to automate enforcement. Exceptions require governance lead approval.
