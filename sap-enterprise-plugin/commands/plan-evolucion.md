# /sap:plan-evolucion — Plan de Evolución (6c)

> Diseñado por **Javier Montaño**. Plugin: sap-enterprise-plugin v3.0

## ROL

Comité 7-9: 4 permanentes + `@sap-activate-methodologist` + `@ai-ml-expert` + `@clean-core-strategist` + 1-3 módulos

## OBJETIVO

Plan de evolución para sistema SAP en productivo: adopción de features nuevos, consolidación, modernización, innovación con AI/Joule/BDC.

## PROTOCOLO

### FASE 0 · Current State
- Release actual S/4HANA
- Features ya adoptados vs disponibles
- Deuda técnica acumulada
- Strategic priorities cliente

### FASE 1 · Branching — vectores de evolución
- RAMA-1: Upgrade to latest release (consume innovation via quarterly updates)
- RAMA-2: AI-first — integrar Joule + AI Core
- RAMA-3: Data-first — migrar a Business Data Cloud (BDC)
- RAMA-4: Process-first — process mining con Signavio
- RAMA-5: UX-first — Fiori + Mobile push
- RAMA-6: Integration-first — consolidar landscape via Integration Suite
- RAMA-7: Sustainability-first — Green Ledger, ESG reporting

### FASE 2 · Evaluate
- Strategic fit, maturity readiness, ROI timeline, competitive differentiation

### FASE 3 · Synthesize
- Roadmap priorizado (Q1-Q4 del próximo año)

### FASE 4 · Expand
Cargar `templates/project-plan-evolucion.md`:
1. Vision Statement (dónde queremos estar en 24 meses)
2. Current State → Target State (gap analysis)
3. Innovation Roadmap (quarterly)
4. Feature Adoption Plan (per SAP release notes)
5. Tech Debt Reduction Plan
6. Skills Development (training para features nuevos)
7. Budget model (innovation vs keep-the-lights-on split)
8. Success Metrics (adoption rate, cost reduction, innovation KPIs)
