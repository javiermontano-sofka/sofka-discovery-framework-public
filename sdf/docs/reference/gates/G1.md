# Gate G1 — Discovery completeness

- **When**: After P0 (Plan) → P4 (Flow Mapping) complete.
- **Responsible**: quality-guardian (lead), risk-controller, subject-matter-expert, domain-analyst.

## Blockers

| # | Condition | Remediation |
|---|-----------|-------------|
| G1.1 | AS-IS (P3) has <60 % evidence tags at priority 1-4 (`[CÓDIGO]`/`[ADJUNTO]`/`[CONFIG]`/`[DOC]`) | Upgrade evidence; add interviews; re-ingest attachments |
| G1.2 | Scope (P2) is unbounded — no explicit out-of-scope section | Add out-of-scope bullets; confirm with stakeholder |
| G1.3 | Stakeholder map (P1) missing critical roles (per `{TIPO_SERVICIO}`) | Name missing stakeholders; schedule interviews |
| G1.4 | Flow mapping (P4) has orphaned steps (in → no out, or vice versa) | Close loops; name the out-of-system handoff |
| G1.5 | `[SUPUESTO:severity=CRÍTICO]` present in P3 or P4 | Upgrade or defer with explicit next-step |

## Pass criteria

- All 5 P-stages delivered.
- Evidence density ≥ 60 % priority 1-4.
- Ghost menu present on every deliverable.
- No critical `[SUPUESTO]` unresolved.

## Verdict format

```
G1 verdict: PASS|FAIL|ADVISORY
- Deliverables reviewed: 5 (P0..P4)
- Evidence density: N %  (target ≥ 60)
- Unresolved critical supuestos: M  (target 0)
- Blockers: [list]
```
