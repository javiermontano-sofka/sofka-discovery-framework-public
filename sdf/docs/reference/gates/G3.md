# Gate G3 — Final deliverable review

- **When**: After P7 (Spec) → P9 (Handover) complete; last gate before client delivery.
- **Responsible**: quality-guardian (lead), risk-controller, editorial-director, ux-strategist (if applicable).

## Blockers

| # | Condition | Remediation |
|---|-----------|-------------|
| G3.1 | Missing `## Siguientes pasos` on any deliverable | Add ghost menu per [ADR-0016](../../adr/0016-ghost-menu-every-artifact.md) |
| G3.2 | Evidence density < 70 % priority 1-4 overall | Upgrade tags; re-interview; cite attachments |
| G3.3 | Brand violation (green color, wrong font, off-palette) | Re-render with canonical tokens |
| G3.4 | Markdown-Excellence failures (no TL;DR, wall-of-text) | Re-structure per [ADR-0013](../../adr/0013-markdown-excellence-style.md) |
| G3.5 | HTML render doesn't match sample deliverables | Use `/sdf:render-html` not an ad-hoc converter |
| G3.6 | Unresolved `[SUPUESTO:severity=CRÍTICO]` | Upgrade or defer |
| G3.7 | Cross-deliverable inconsistency (numbers don't match between P3, P6) | Reconcile; quality-guardian spots |

## Pass criteria

- All deliverables in final format with ghost menus.
- Evidence density ≥ 70 %.
- Brand-compliant rendering.
- Cross-deliverable consistency checked.

## Verdict format

```
G3 verdict: PASS|FAIL
- Deliverables reviewed: N
- Evidence density overall: M %
- Brand compliance: PASS|FAIL
- Consistency check: PASS|FAIL  (spots: [list])
- Critical supuestos unresolved: K  (must be 0)
```
