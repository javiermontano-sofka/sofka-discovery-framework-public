# Gate G2 — Budget + timeline bounded

- **When**: After P5 (Scenarios) → P6 (Roadmap + Cost Estimation) complete.
- **Responsible**: delivery-manager (lead), economics-researcher, quality-guardian.

## Blockers

| # | Condition | Remediation |
|---|-----------|-------------|
| G2.1 | Point-value costs (e.g. "20 FTE-meses" not "18-24") | Add range; cite basis |
| G2.2 | No disclaimer ("Estimación no comercial …") | Add banner |
| G2.3 | Currency symbols present (`$`, `€`, `USD`) | Remove; convert to FTE-meses |
| G2.4 | FTE count implausible (>2× or <0.5× benchmarks) | Justify deviation with `[INFERENCIA]` |
| G2.5 | Roadmap milestones lack ghost-menu next-step | Add named owners + dates |

## Pass criteria

- All estimates in FTE-meses with ranges.
- Disclaimer present on every cost-bearing page.
- No price/currency leakage ([ADR-0011](../../adr/0011-never-prices-only-fte.md)).
- Roadmap milestones named + dated + owned.

## Verdict format

```
G2 verdict: PASS|FAIL|ADVISORY
- Cost estimates: N  (all with ranges: yes/no)
- Disclaimers present: N/M
- Currency leaks: 0 required
- Roadmap milestones: N  (all owned: yes/no)
```
