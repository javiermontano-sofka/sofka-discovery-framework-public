# UX-Design — UX research + design systems

## Scope signal

- "UX refresh" · "Design system" · "User research" · "Customer journey" · "Accessibility audit" · "Persona development"

## Committee

Permanent triad + ux-strategist (lead) · ux-researcher · frontend-developer · accessibility-specialist · customer-success-architect · design-thinking-facilitator.

## Pipeline variant

- P3 AS-IS = current UX audit + heuristic evaluation + accessibility score (WCAG).
- P5 scenarios = design-system options · research program options.
- G1.5 feasibility: research feasibility (recruitment, budget) + tech constraints.

## Typical deliverables beyond P0-P9

- Persona set (evidence-backed).
- Customer journey maps.
- Design system blueprint (tokens, components, governance).
- Accessibility remediation plan.

## Anti-patterns

- "Build a new website" → UX-Design + SDA combined; route per dominant outcome.
- "Brand refresh" → branding is brand-adjacent to UX but often separate.
