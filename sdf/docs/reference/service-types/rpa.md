# RPA — Robotic Process Automation

## Scope signal

- "Automatizar procesos" · "Bots UiPath / Automation Anywhere / Power Automate" · "Back-office repetitive tasks" · "Process mining"

## Committee

Permanent triad + process-automation-specialist (lead) · business-analyst · technical-architect · security-architect (credential vaulting) · change-catalyst.

## Pipeline variant

- P3 AS-IS = process inventory + mining.
- P5 scenarios = per-process readiness scoring (ROI × risk × stability).
- G1.5 feasibility: credential handling, exception frequency, UI stability.

## Typical deliverables beyond P0-P9

- Process inventory with automation readiness scores.
- Bot architecture (orchestrator + queues + exception paths).
- Automation ROI model.
- Change-management plan (humans displaced or re-skilled).

## Anti-patterns

- "AI-powered automation" → check signal; if it's LLM-driven workflows, route to Data-AI + RPA hybrid.
- Unstable UI targets → may require intelligent extraction → Data-AI.
