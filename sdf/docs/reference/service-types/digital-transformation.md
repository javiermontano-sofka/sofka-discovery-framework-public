# Digital-Transformation — Cross-cutting multi-service programs

## Scope signal

- "Digital transformation program" · "Enterprise-wide initiative" · "Multi-year modernization" · "Strategic capability uplift"

## Committee

Permanent triad + transformation-architect (lead) · enterprise-architect · change-catalyst · ai-strategist · qa-strategist · process-automation-specialist · cloud-architect · delivery-manager + industry SME.

## Pipeline variant

- P1 Stakeholder map is enterprise-wide (C-suite + multiple BUs).
- P3 AS-IS spans multiple domains; deliver per-domain AS-IS sub-reports.
- P5 scenarios = strategic portfolios + waves.
- G1.5 feasibility focuses on organisational absorptive capacity, not individual technical feasibility.

## Typical deliverables beyond P0-P9

- Transformation KPI framework.
- Cross-workstream dependency map.
- Wave-based roadmap (phase 1 ~ quick wins, phase 2 ~ platform, phase 3 ~ scale).
- Program governance model.

## Anti-patterns

- "Single-tool roll-out" with a transformation label → route to the specific type.
- Scope creep from Multi-Service → Digital-Transformation requires strategic intent, not just many workstreams.
