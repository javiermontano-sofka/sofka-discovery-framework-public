# Data-AI — Data platforms, ML, analytics

## Scope signal

- "Data platform" · "ML models in production" · "Analytics layer" · "LLM integration" · "Agentic AI" · "Data mesh / fabric"

## Committee

Permanent triad + ai-strategist (lead) · ai-architect · data-architect · data-engineer · analytics-architect · data-scientist · ai-agent-architect (if agentic) · security-architect · devsecops-expert.

## Pipeline variant

- P3 AS-IS = data inventory + lineage + quality audit.
- P5 scenarios = architecture patterns (lakehouse · mesh · LLM-native).
- G1.5 feasibility: data readiness, model evaluability, responsible-AI framework.

## Typical deliverables beyond P0-P9

- Data readiness score.
- MLOps maturity assessment.
- Responsible-AI framework application.
- Agent evaluation framework (if agentic).

## Anti-patterns

- "Just a BI dashboard" → Analytics-only, no ML — still Data-AI but simpler.
- "AI-powered search" without domain data → clarify; might be UX-Design + infra.
