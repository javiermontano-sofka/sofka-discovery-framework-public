# Cloud — Migration, landing zone, FinOps

## Scope signal

- "Cloud migration" · "AWS/GCP/Azure landing zone" · "Reduce cloud costs" · "Multi-cloud" · "FinOps" · "Lift-and-shift vs re-platform"

## Committee

Permanent triad + cloud-architect (lead) · platform-engineer · devops-engineer · security-architect · devsecops-expert · economics-researcher (TCO).

## Pipeline variant

- P3 AS-IS = current footprint + cost baseline.
- P5 scenarios = 7R framework (retain, retire, relocate, re-host, re-platform, re-factor, re-purchase).
- G1.5 feasibility: network blast radius, data gravity, cost projections.

## Typical deliverables beyond P0-P9

- Cost baseline + target TCO.
- 7R scenario per workload.
- Landing zone architecture (accounts/subscriptions + IAM + networking).
- FinOps governance model.

## Anti-patterns

- "Kubernetes expertise" → often part of Cloud, sometimes pure SDA.
- "Edge-cloud hybrid" → specialised; may need edge-computing-specialist.
