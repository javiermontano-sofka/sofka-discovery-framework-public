# SAS — Staff Augmentation as Service

## Scope signal

- "Necesitamos X desarrolladores" · "Ampliar el equipo" · "Roles específicos por N meses" · "Ramping up"

## Committee

Permanent triad + delivery-manager (lead) · product-strategist · technical-lead · change-catalyst · talent-assessor (from pm:).

## Pipeline variant

- P1 Stakeholder map emphasises reporting lines + integration with internal team.
- P3 AS-IS = skills inventory + gap analysis.
- P5 scenarios = blended team models (ramp profiles).
- G2 cost model = rate-card × ramp schedule, not outcome-based.

## Typical deliverables beyond P0-P9

- Role catalogue + seniority mix.
- Onboarding protocol + knowledge transfer plan.
- Performance + escalation framework.

## Anti-patterns

- "You deliver X feature" → outcome-based; that's SDA not SAS.
- "Train our team" → Training/Management hybrid.
