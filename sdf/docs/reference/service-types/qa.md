# QA — Quality-as-a-service

## Scope signal

- "Queremos externalizar QA" · "Test factory" · "Automation from zero" · "TMMi assessment" · "Improve test coverage"

## Committee

Permanent triad + qa-strategist (lead) · quality-engineer · technical-lead · full-stack-generalist (for codebase reality check).

## Pipeline variant

- P3 AS-IS = TMMi maturity assessment.
- P5 scenarios = CoE structure options + automation maturity roadmaps.
- G1.5 feasibility emphasises test-data availability + environment parity.

## Typical deliverables beyond P0-P9

- TMMi maturity score (1-5).
- Test factory structure (roles + RACI).
- Automation pyramid + coverage targets by layer.
- Quality governance framework.

## Anti-patterns

- "Just run our tests" (pure execution, no strategy) → out of SDF scope; route to operational QA.
- "Build a test tool" → SDA with QA domain.
