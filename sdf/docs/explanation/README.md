# Explanation — understanding-oriented

**Diátaxis quadrant**: discursive. Answers "why is it this way?". Context, background, trade-offs, history.

Explanations are where prose is allowed to breathe. They exist so that a thoughtful reader can disagree well, not just execute.

## Explanation style rules

- **Cite primary sources** — methodologies (Procida for Diátaxis, Nygard for ADRs, etc.), with year.
- **Show the dismissed alternatives** — trade-offs only matter if the losers are named.
- **No refactoring pressure** — essays are append-mostly; supersede via new essay + note at top of old one if the thinking evolves.
- **Link heavily** — an essay is a node in a Zettelkasten-like graph.

## Relationship to ADRs

ADRs record **decisions**. Explanations record **understanding**. An ADR cites the essays that informed it; an essay may cite ADRs that operationalise its ideas.

When a decision changes, you supersede the ADR. The old essay stays as-is (it captured the thinking at the time).
