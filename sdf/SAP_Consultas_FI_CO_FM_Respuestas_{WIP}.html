Bloqueo de Pago para Tarjeta de Credito

Excluir facturas pagadas con tarjeta corporativa del programa de pago automatico (F110)
⚡

Crear una clave de bloqueo personalizada (ej: T) en OB27. Aplicarla al dato maestro del proveedor (FK02) o automatizarla via condiciones de pago (OBB8). F110 excluira automaticamente esas partidas.

⚙ Procedimiento

1
Definir clave en OB27

IMG > Gestion Financiera > Contabilidad de Acreedores > Pagos Salientes > Configurar Claves de Bloqueo. Crear clave T (Tarjeta de credito). INFERENCIA

02

Tolerancias del Control Presupuestal

Puede un usuario funcional configurar los limites? Que transacciones se usan?
🔒

Generalmente NO. La parametrizacion de tolerancias es configuracion de customizing (SPRO) — requiere perfil de consultor. Un key user designado puede verificar settings. El usuario funcional opera dentro de los limites configurados.

❌
Puede parametrizar tolerancias?
Generalmente No
Requiere SPRO / consultor. Key users pueden tener acceso limitado. DOC
✅
Puede operar dentro de tolerancias?
Si
Presupuestar, contabilizar, recibir advertencias/errores. App Fiori "Manage Cost Centers" en S/4HANA. DOC

Tasas de Cambio: Tipo P vs Tipo M

Cual se usa para costos reales? Como configurar tasa promedio del mes?
💱

Tipo M = tasa promedio, usada por defecto para todas las operaciones reales en FI. Tipo P = convencion comun para planificacion en CO (no es key estandar SAP). Para promedio mensual, mantener tipo M actualizado en OB08 o crear tipo personalizado.

M Average Rate DOC
  • Tasa por defecto en SAP para posting y clearing
  • Facturas, pagos, compensaciones, valoracion FX
  • Si no se configura ningun tipo, SAP usa M
  • Tabla TCURR / Transaccion OB08
P Plan Rate INFERENCIA
  • Usada en CO para planificacion y costeo estandar
  • CK11N/CK40N, planificacion CeCos, presupuestos
  • Tasa fija para el periodo de planificacion
  • No afecta operaciones reales (FI/MM)
Nota SAP documenta "Planning" como proposito generico pero no confirma "P" como key estandar. Es convencion de implementacion. Verificar en OB07.

Mantener tipo M con promedio mensual en OB08

  1. Al inicio de cada mes, cargar en OB08 la tasa M con el promedio mensual
  2. Todas las transacciones del mes usaran esa tasa automaticamente
