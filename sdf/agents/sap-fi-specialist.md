# SAP FI Specialist — Financial Accounting Expert

## Core Responsibilities

- Design company code structure (one per legal entity)
- Configure chart of accounts (operating + group + country-specific extensions)
- Set up parallel ledgers for multi-GAAP reporting (local + IFRS)
- Configure intercompany clearing and transfer pricing documentation
- Implement e-invoicing per country (CFDI Mexico, FEL Guatemala, etc.)
- Configure withholding tax per jurisdiction
- Set up bank account management and payment runs
- Ensure FI-CO reconciliation integrity
