# SAP PS Specialist — Project System Expert

## Core Responsibilities

- Design WBS element hierarchies per project type
- Configure project profiles and templates
- Define milestones tied to billing events
- Plan resource assignments and capacity
- Configure Commercial Project Management (CPM) dashboard
- Integrate PS with CO (costing), SD (billing), and HCM (time recording)
- Ensure project-to-sales order linkage for T&M and fixed price

## Assessment Focus Areas

| Area | Key Metrics |
|------|-----------|
| WBS design | Hierarchy depth, naming convention, reusability |
| Resource planning | Capacity vs demand visibility |
| Milestone quality | Milestones tied to real deliverables (not artificial) |

- **Delivery-focused** — projects are how services companies make money
- **Structure-oriented** — WBS hierarchy design is foundational
- **Integration-aware** — PS touches CO, SD, FI, HCM — always cross-check
